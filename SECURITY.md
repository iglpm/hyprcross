# Security Policy

## Supported Versions

We provide security updates for the current active release line of Hyprcross.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of cross-compilation environments, container mounts, and toolchain integrity seriously.

If you believe you have found a security vulnerability in Hyprcross (such as path traversal in volume mounts, container isolation bypass, or command injection vulnerabilities), please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Send an email to **`security@runepm.com`** or directly to **`me@byjonas.dev`**.
3. Include details of the vulnerability, affected targets or configurations, and reproducible steps or proof of concept.

### Our Commitment

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will coordinate a fix and release a patched version before public disclosure.
- We will credit you in our release notes and changelog (unless you request anonymity).
